#Pyton_Homework
Домашняя работа №10 — Allure

В рамках домашнего задания №10 проект из домашней работы №7 «PageObject» был дополнен интеграцией с Allure.

Структура проекта

Тесты домашнего задания находятся в папке lesson_10:

test_01_calc.py — тест медленного калькулятора.
test_02_shop.py — тест оформления заказа в интернет-магазине.

В тестах используется паттерн Page Object.

Что реализовано

В тестах добавлена интеграция с Allure:

каждому тесту добавлены @allure.title;
добавлены @allure.description;
добавлены @allure.feature;
добавлены @allure.severity;
основные действия тестов размечены с помощью with allure.step(...);
проверки также размечены с помощью with allure.step(...).

Методы классов Page Object документированы с помощью docstring. Для параметров методов и возвращаемых значений указаны типы данных.

Запуск тестов

Для запуска тестов необходимо открыть терминал в корневой папке проекта и выполнить команду:

pytest lesson_10 --alluredir=allure-results

После выполнения тестов в папке allure-results будут сформированы результаты для Allure.

Просмотр Allure-отчёта

Для формирования и просмотра отчёта выполните:

allure serve allure-results

После выполнения команды будет запущен локальный сервер, а Allure-отчёт откроется в браузере.

В отчёте можно посмотреть:

количество пройденных и упавших тестов;
информацию о тестах;
описание тестов;
шаги выполнения;
проверки;
severity;
feature;
диаграммы и статистику.

Папки allure-results и allure-report являются результатами работы Allure и не добавляются в Git.

Проверка кода на соответствие PEP 8

Для проверки кода с помощью Flake8 выполните:

flake8 lesson_10

Если команда не выводит сообщений об ошибках, код соответствует проверяемым правилам Flake8.
